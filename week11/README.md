# Computer Lab Access System

## Project Description
A simple Python application that uses modular programming to determine whether a student can access the computer lab.

## Conditions for Access
Access is granted only if:
- The student is registered.
- The lab is open.
- A computer is available.

Otherwise, the program displays the reason for denial.

## Project Structure
- main.py – Connects all modules and controls the program flow.
- student.py – Collects student information.
- access.py – Checks access status and returns the reason.
- display.py – Displays the final result.

## Work flow 
Enter the required information, and the program will display the access status and reason.
