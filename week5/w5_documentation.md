# Week 5 Documentation

## 1.1 Problem Statement
Create a Python program that helps a café calculate a customer's bill automatically based on the quantity of Coffee, Tea, and Sandwich purchased.

## 1.2 Inputs
- Customer name
- Coffee quantity
- Tea quantity
- Sandwich quantity

## 1.3 Outputs
- Total bill (RM)

## 1.4 Typical Process Flow
1. Read the customer's name.
2. Read the quantity of Coffee.
3. Read the quantity of Tea.
4. Read the quantity of Sandwich.
5. Calculate the total price.
6. Display the receipt and total amount.

## 1.5 Constraints
- Quantities must be zero or positive integers.
- Item prices are fixed:
  - Coffee = RM 8.50
  - Tea = RM 6.00
  - Sandwich = RM 12.00

## 2. Problem Decomposition
- Get customer information.
- Read item quantities.
- Calculate the total bill.
- Print the receipt.

## 3. Pseudocode

START

Input customer name

Input coffee quantity

Input tea quantity

Input sandwich quantity

Calculate total:
total = (coffee × 8.50) + (tea × 6.00) + (sandwich × 12.00)

Display receipt

Display total bill

END
