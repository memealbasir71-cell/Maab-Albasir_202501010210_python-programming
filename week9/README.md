## IT helpdesk ticket registration system 
The app useed to register IT helpdesk for student and assin technician based on the selected priority level.

## Tech stack 
- Python 3

## How to use:
1. Open the project folder.
2. Run 'main.py'
3. Enterthe required info
4. Select the priority level
5. The system display the completed pelpdesk ticket

## Technician assignment 
Priority = Technician 
High = Ahmad
Medium = Siti
Low = Ali

## status
Every created ticket is assigned the status (Pending)
